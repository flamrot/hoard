Arrow keys move between blocks. Enter opens a folder, Backspace goes up, S marks the block for removal, Shift+F10 shows options. The list in the side panel shows the same items.

How to read the map Every block is a folder or file. The bigger the block, the more space it uses. Colours show the kind of file. Double-click a folder to look inside · Backspace to go back · right-click for options. With the keyboard, Tab to the map and use the arrow keys and Enter.
